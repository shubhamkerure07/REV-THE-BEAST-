# 🏎️ REV-THE-BEAST

### Experience the machine. Feel the power. 🔥

**REV-THE-BEAST** is an interactive automotive web project created for people who love **cars, engines, speed, and engineering**.

The project brings together car specifications, performance information, visuals, and an immersive interface to make exploring performance machines more interesting than simply reading a specification sheet.

---

## 🚀 Features

- 🏎️ Explore a selection of performance cars
- ⚙️ View important engine and performance specifications
- 📊 Explore horsepower, torque, and other vehicle data
- 🔊 Experience engine sounds
- 🎨 Automotive-inspired dark UI
- ✨ Interactive and animated interface
- 📱 Responsive design for different screen sizes
- 🚗 Learn more about the engineering behind selected machines

---

## 🛠️ Built With

- ⚛️ React
- 📘 TypeScript
- ⚡ Vite
- 🎨 CSS
- 🔊 Audio
- 🧩 Component-based architecture
