# 🏎️ REV-THE-BEAST

### Experience the machine. Feel the power. 🔥

**REV-THE-BEAST** is an interactive automotive web project built for people who love **cars, engines, speed, and engineering**. Instead of reading a flat spec sheet, you explore a selection of performance cars, dig into their engine and performance data, and actually **hear** them.

---

## 🚀 Features

- 🏎️ Explore a selection of performance cars
- ⚙️ View engine and performance specifications
- 📊 Horsepower, torque, and other vehicle data
- 🔊 Listen to engine sounds
- 🎨 Automotive-inspired dark UI
- ✨ Interactive, animated interface
- 📱 Responsive design across screen sizes

---

## 🚀 Getting Started

**Prerequisites:** [Bun](https://bun.sh) (this project ships a `bun.lock`)

```bash
git clone https://github.com/shubhamkerure07/REV-THE-BEAST-.git
cd REV-THE-BEAST-
bun install
```

Copy `.env.example` to `.env` and fill in any required values before running the app.

```bash
bun run dev
```

---

## ▶️ Usage

Once running locally, open the app in your browser to browse the featured cars, view their specs, and play their engine sounds.

---

## 🔐 Security

- Never commit a real `.env` file — only `.env.example` (with placeholder values) belongs in the repo.
- Double-check `.gitignore` excludes `.env` before pushing changes.
